BEFORE YOU BEGIN

A beta, with care.

Live operations use real assets and fees. Review assets, recipients and fees, set explicit limits and approve only an operation you understand. A small balance reduces exposure; it does not remove it.

Closing to the tray can leave an authorized session running. Use Exit to stop the app. Pause stops new work and cannot reverse an operation already submitted.

Updates are manual. Some translations and layouts are still being refined. The guide describes current limitations and installation checks.

!

Unexpected spending or loss of control?

Stop new activity. Use Pause or Exit if available, preserve your profile and check Activity before retrying an uncertain send. Select Important spending or security concern in the form. The form is not monitored continuously.
