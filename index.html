TRAVEL WITH CARE

Curiosity, with
a little caution.

Live operations use real assets and fees. Use a dedicated test wallet with small balances. Review assets, recipients and fees, set explicit limits and approve only an operation you understand.

Closing to the tray can leave an authorized session running. Use Exit to stop the app. Pause stops new work; it cannot reverse an operation already submitted.

Updates are manual. Some translations and layouts are still being refined. The guide covers installation checks and current limitations.

!

Unexpected spending or loss of control?

Stop new activity. Use Pause or Exit if available, preserve your profile and check Activity before retrying an uncertain send. Select Important spending or security concern in the form. The form is not monitored continuously.
